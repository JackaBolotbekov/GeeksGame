# GeeksGame

Игровая платформа Geeks, отделённая от Geeks Service.

## Ветки

- `prod` — стабильная версия.
- `dev` — интеграционная разработка и новые игры.

## Локальный запуск

```bash
npm install
npm run dev
```

Первая игра находится в центральном разделе `Game`: змейка работает с клавиатуры (`WASD`/стрелки) и свайпов.

База данных и production-секреты в репозиторий не входят. Схемы и миграции сохранены как часть кодовой базы.
